# 📝 과제 1. Vanilla JS Todo App

Vanilla JavaScript만을 사용하여 Todo 웹 애플리케이션을 구현한 프로젝트입니다.


## 🚀 실행 방법

### 1. 저장소 클론

```bash
git clone 저장소주소
cd kakao-assignment-1
```

### 2. 프로젝트 실행

* VS Code에서 프로젝트 열기
* `index.html` 파일 열기
* Live Server 실행

  * `index.html` 우클릭
  * **Open with Live Server** 선택

---

## 📁 프로젝트 구조

```text
kakao-assignment-1/
├── index.html   # 화면 레이아웃
├── style.css    # 스타일
├── app.js       # 기능 구현
└── README.md
```

---

## ✅ 구현 기능

### 기본 미션

* Todo 생성 (Create)
* Todo 수정 (Update)
* Todo 완료 처리
* Todo 삭제 (Delete)
* 상태별 필터링

  * 전체
  * 진행 중
  * 완료
* 날짜별 Todo 관리 (일간 뷰)
* LocalStorage 연동

  * 새로고침 후에도 데이터 유지

### 도전 미션

* 주간 뷰 제공
* 이전 주 / 다음 주 이동
* 날짜 선택 기능
* 날짜별 Todo 개수 표시
* 오늘 날짜 강조 표시

---

## 🛠️ 사용 기술

* HTML5
* CSS3
* Vanilla JavaScript
* Web Storage API (LocalStorage)
